NoX Core for Apple Silicon

Requires macOS 26 or later and your own copy of Nox. The app includes no original game assets.

Place NoX Core.app in your Nox data folder, or copy the game's data to ~/Library/Application Support/NoXCore/GameData. In Finder, choose Go → Go to Folder to open that location.

Saves, settings and backups

Characters and campaign saves are in ~/Library/Application Support/NoXCore/UserData/Save. Settings (nox.cfg and noxcore.cfg) are in the parent UserData folder. These locations are separate from the app and game data.

In Finder, press Shift–Command–G (Go → Go to Folder) and paste the path. The ~ means your home folder. The game creates these directories on first use.

To back up or transfer progress, quit the game and copy the whole Save folder, including its subfolders. To restore it, quit the game, keep a copy of the current folder, and replace it with your backup. Copy the two settings files too if you want to keep them. Replacing NoX Core.app during an update leaves these files in place.

Existing settings and saves from the selected game-data folder are imported once without overwriting user files. The originals remain in place. Later launches do not repeat the import or restore deleted characters.

From Terminal, --user-dir "/path/to/UserData" changes the settings location and the default save location to its Save subfolder. An explicit --save-dir "/path/to/Save" overrides the save location and skips automatic save import.

The log is ~/Library/Application Support/noxcpp/noxsdl/noxcore-log.txt.

The notch/safe-area fix is not included yet. Exclusive fullscreen on a notched display has a known layout/input limitation; use windowed mode if content or pointer alignment is affected.

This app is ad-hoc signed, not Developer ID signed or notarized. You can build and sign your own copy with the commands in BUILDING.txt; no paid developer account is required.
